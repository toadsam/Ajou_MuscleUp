## 1. 내 종목 이름 고치기
- **서버**
  - `PATCH /api/lifts/custom/{code}` `{ name, category }` → `ExerciseCatalog.update`
  - 코드(`C`+번호)는 그대로라 **지난 기록 · 개인 최고 · 그래프도 새 이름으로** 보인다.
  - 거절하는 것
    - 다른 내 종목이나 기본 종목과 같은 이름(띄어쓰기 · 대소문자 무시) → 409
    - 빈 이름 · 모르는 부위 → 400
    - 남의 종목 → 404
  - 자기 이름은 띄어쓰기만 바꿔도 된다.
  - 맨몸 여부는 바꾸지 않는다. 지난 기록의 무게 0 세트와 맞지 않게 될 수 있어서다.
- **화면**: 종목 고르기 "내 종목" 탭에서 종목마다 "고치기"를 누르면 이름 · 부위를 고치는 칸이 그 자리에 열린다(`ExercisePicker`).
- `lib/lifts.ts` `updateCustomExercise` 가 여러 화면이 같이 쓰는 목록을 바로 바꾼다.

## 2. 식단 "내 음식"
- **새 표 `my_foods`**(`MyFood`): 이름(60), 양(자유 글 30), 칼로리, 단백질 · 탄수화물 · 지방. 값은 "그 양" 기준이다.
  - 한 사람이 100개까지 만들 수 있다.
  - 탈퇴하면 지운다(`AccountDeletionService`, `AccountSafetyTest`).
- **API**(`/api/diet/my-foods`, 본인만)
  - 목록 · 저장 · 고치기 · 지우기
  - 저장은 **같은 이름이 있으면 그 음식을 새 값으로** 바꾼다.
- 범위 검사는 식단 기록과 같은 규칙을 쓴다(`DietService.range` / `grams` 를 패키지 안에서 같이 쓰도록 열었다).
- **화면**(`Diet.tsx` 음식 추가 창)
  - **"내 음식으로 저장"** 체크. 기록이 저장된 뒤 같이 저장하고, 실패하면 알리기만 한다.
  - 위쪽에 "내 음식" 칩이 있다. 누르면 이름 · 양 · 영양소가 채워진다. "지우기"를 누르면 칩마다 ×가 붙는다.
  - 이름 검색 목록 맨 위에 이름이 맞는 내 음식이 노란 "내 음식" 표시로 먼저 나온다(`FoodSearchField` `mine` · `onPickMine`).
  - 검색 결과가 없을 때 문구로 "내 음식으로 저장"을 안내한다.
- 바코드는 하지 않았다(사용자 목록에 없음).

## 3·5. 다른 사람에게도 보이는 "겉모습" — `AvatarLookService`(새)
- 한 서비스가 두 가지를 같이 준다. 여러 명은 쿼리 두 번으로 한꺼번에 읽는다.
  - **도감에서 장착한 민소매 색 · 칭호**(`user_collections`)
  - **펌핑이 끝나는 시각**: 마지막 운동 세션 `endedAt` + 1시간, 아직 안 지났을 때만
- 실리는 곳

  | 어디 | 무엇 |
  |---|---|
  | `GET /api/character/me` | `pumpedUntil`(ms), `tank` |
  | 친구 목록 · 검색 · 요청(`FriendCharacterResponse`) | `tank`, `title`, `isPumped` |
  | 모임 멤버 · 챌린지(`CrewMemberAttendanceResponse`, `CrewChallengeMemberProgressResponse`) | `tank`, `isPumped` |
  | 라운지 입장권(`RealtimeTicketController`) | `pump`, `tank`, `ttl` → 실시간 서버 `PlayerState.isPumped · tank · title` |

- 실시간 서버는 입장권 값만 믿는다. `tank` 는 `#RRGGBB` 만 받고, 칭호는 20자로 자른다.
- **그림**
  - `AvatarRenderer` 에 `tank` · `pumped` prop을 더했다.
    - `tank`: 다른 사람 캐릭터에서 이 기기 저장값보다 먼저 쓴다.
    - `pumped`: 근육 한 단계에 관자놀이 땀, 어깨 위 김(`spec.pumped`)을 더한다.
  - 휴식 중이면 펌핑을 그리지 않는다.
- **화면**
  - 홈(내 캐릭터): `pumpedUntil` 이 지나지 않았으면 펌핑, 장착 민소매는 서버 값을 쓴다.
  - 운동 세션 결과 화면: "펌핑 완료! 1시간 동안 근육이 한 단계 커 보여요"와 펌핑된 캐릭터.
  - 친구 목록 · 모임 챌린지 화면의 캐릭터에 장착 민소매 · 펌핑을 붙였다.
  - 라운지
    - 지도 캐릭터(`PlayerAvatar`)와 프로필 카드에 장착 민소매 · 펌핑을 붙였다.
    - 프로필 카드에 칭호 칩과 "펌핑 중" 칩을 띄운다.

## 4. 러닝 중 달리는 캐릭터 — `components/running/RunTrack.tsx`(새)
- 옆모습 달리기 동작(`pixelPoses` `run`)을 넣었다. 두 장면에서 팔다리가 번갈아 나가고, 한 장면은 한 칸 떠오른다.
- **지금 페이스로 박자를 정한다**
  - 한 걸음 = 페이스(초/km) × 0.5ms, 120~360ms로 자른다. 5'00"/km면 150ms, 7'00"면 210ms.
  - 바닥 줄도 같은 빠르기로 흐른다(`.run-ground-move`, `--run-dur`).
- **다음 1km 깃발**이 오른쪽에서 다가와, 1km를 채우는 순간 캐릭터를 지나간다.
- 멈춤이면 선 자세에 "숨 고르는 중"을 띄운다. 움직임 줄이기 설정이면 멈춘 그림만 보인다.
- 러닝 화면(`Running.tsx`) 큰 거리 숫자 아래에 둔다. 캐릭터 · MBTI는 달리기를 시작하면 한 번 불러온다.

## 6. 라운지 "운동 구역" — `LiveActivityService`(새) · `components/lounge/LiveZone.tsx`(새)
- **설계를 바꾼 이유**: 운동 중인 사람은 운동 세션 · 러닝 화면에 있어서 라운지에 접속해 있지 않다.
  - 그래서 실시간 서버의 접속 목록으로는 "운동 중"을 보여 줄 수 없다.
  - 대신 **운동 세션 · 러닝 화면이 1분마다 서버에 알리고**(`PUT /api/live`), 서버가 3분 동안 기억한다.
- **서버**(`/api/live`, 로그인한 사람만)
  - `PUT { activity: WORKOUT|RUN, exercise }`: 남의 직접 추가 종목 · 모르는 코드는 종목 없이 "운동 중"으로만 받는다.
  - `DELETE`: 끝내기 · 그만두기 · "보이기" 끔 · 화면을 떠날 때 보낸다.
  - `GET`: `{ count, items }`, 최근에 시작한 순으로 12명까지.
    - 닉네임, 종목 이름 · 부위, 캐릭터 겉모습(티어 · 단계 · 성장값 · 장착 민소매 · 펌핑), 시작 시각.
    - **이메일 · 사용자 번호 · 무게는 싣지 않는다.** 내 것은 `mine`.
    - 같은 목록을 10초 동안 다시 쓴다.
  - **서버 메모리에만** 둔다. 재시작하면 비지만 1분 안에 다시 찬다. 백엔드가 여러 대가 되면 공유 저장소가 필요하다.
- **알리는 쪽**(`lib/live.ts` `useLiveHeartbeat`)
  - 운동 세션은 마지막으로 만진 종목을 알린다. 러닝은 달리는 동안만 알리고, 멈춤이면 끝낸다.
  - 둘 다 **"라운지에 보이기"** 체크로 끌 수 있다(기본 켬, 이 기기에 저장).
  - 화면이 꺼져 있으면 보내지 않는다. 3분 뒤 빠진다.
- **라운지 "운동 구역"**(광장 오른쪽 칸 맨 위)
  - "지금 운동 중 N명"을 띄우고, 사람마다 캐릭터가 **그 종목 동작**을 0.8초 박자로 반복한다.
  - 바벨은 무게를 보내지 않으므로 60kg 원판으로 그린다. 러닝은 달리는 동작이다.
  - 닉네임 · 종목 이름이 보이고, 내 것은 "나"와 노란 테두리다.
  - 20초마다 다시 부른다(다른 탭에 가 있으면 건너뜀).
- 처음에는 첫 불러오기도 "화면이 안 보이면 건너뛰기"에 걸릴 수 있어서 "불러오는 중"에 머물렀다 → 첫 번째는 항상 부르게 고쳤다.
