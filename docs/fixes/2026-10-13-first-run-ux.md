# 2026-10-13 · 처음 온 사람 시점 점검(홈) + 바로 가기 바꾸기

로컬(375px)에서 두 경우를 처음부터 따라갔다.
1. 로그인 안 한 첫 방문: 저장소를 비우고 `/`.
2. 막 가입한 새 계정: 로컬 DB 에만 빈 시험 계정(기록 0개)을 만들어 로그인. 확인 뒤 계정과 딸린 행을 모두 지웠다.

## 잘 되는 것
- 첫 화면부터 헬스장 지도 · 픽셀 캐릭터가 보여서 "어떤 서비스인지"는 바로 느껴진다.
- 로그인 없이 "내 캐릭터부터 만들어요" → "이걸로 둘러보기" → 캐릭터가 체크기로 걸어가 "출석 체험" 창 → "원판 꽂아 보기"(원판이 날아가 꽂힘) → "이렇게 원판이 쌓여요 · Google로 시작하기". 체험에서 가입까지 길이 한 줄로 이어진다.
- 새 계정 홈에 "바닥을 눌러 걸어보세요" 안내와 "지금 해야 할 일"(출석 · 식단 1끼 · 응원 1번)이 있다.

## 이번에 고친 것
- 바로 가기 버튼을 **출석 · 식단 · 운동 시작 · 내 기록**으로 바꿨다(사용자 요청). 라운지 · 캐릭터는 지도(라운지 · 거울)와 메뉴에 그대로 있다.
  - 출석 · 내 기록: 예전처럼 지도에서 그 자리로 빠르게 걸어가 창을 연다.
  - 식단(`/diet`) · 운동 시작(`/workout/session`): 지도에 장소가 없어 그 화면으로 바로 넘어간다(`Link`). 로그인 전에는 로그인 화면으로.
  - 로그인 전 안내 문구 "걷지 않고 바로 이동" → "자주 쓰는 곳으로 바로"(이제 모두 걸어가는 버튼이 아니라서).
