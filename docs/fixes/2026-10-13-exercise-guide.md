## 1. 그림 코드 정리 — `components/avatar/pixelGrid.ts`(새)
- `pixelAvatar.ts`에 있던 공용 바탕을 옮겼다: 칸 `Grid`, 외곽선, `shade`, 원판 색 · 원판 원(`disc`, `plateColors`), 상수.
- `pixelAvatar.ts`는 예전처럼 `CELL` · `GRID_*` · `INK`를 다시 내보낸다. 그래서 다른 파일은 바꾸지 않았다.
- 예전 그림(진화 단계 · 티어 · 근육)이 그대로인 것을 `/dev/avatars`에서 확인했다.

## 2. 기구 · 옆모습 동작 13가지 — `components/avatar/pixelPoses.ts`(새)
- **관절 좌표 데이터**: 머리 · 어깨 · 엉덩이 · 무릎 · 발 · 팔꿈치 · 손을 프레임 두 장씩 적어 둔다. 이것을 굵은 네모 붓 선으로 잇는다.
  - 굵기: 몸통 4, 허벅지 3, 위팔 3. 근육 단계 2 이상이면 1씩 더 굵다.
  - 반바지는 허벅지 위쪽 45%와 몸통 아래 15%에 칠한다. 벨트 · 머리띠는 티어를 따른다.
  - 다리 · 팔이 둘이면 먼 쪽을 어둡게, 가까운 쪽을 몸 앞에 그린다.
  - 머리는 5×5에 모서리를 깎는다. 정수리 방향(`crown`)과 얼굴 방향(`look`)으로 머리카락 · 눈 · 코를 정한다.
- **기구**: 사각형이나 선으로 적는다(`back` 몸 뒤, `front` 몸 앞).
  - 기구 색은 짙은 철색, 패드는 가죽색이다.
  - 케이블은 `cable` 점에서 손까지 1칸 선으로 긋는다.
- **동작**

  | kind | 종목 | 프레임 0 → 1 |
  |---|---|---|
  | legpress | 레그 프레스 | 무릎 굽힘 → 발판을 밀어 폄 |
  | legcurl | 레그 컬 | 엎드려 다리 폄 → 발뒤꿈치를 엉덩이 쪽으로 |
  | legext | 레그 익스텐션 | 앉아 무릎 굽힘 → 폄 |
  | calf | 카프 레이즈 | 발판 위 → 발끝으로 2칸 올라감 |
  | lunge | 런지 | 다리 벌려 섬 → 깊게 내려감 |
  | row | 바벨 로우, 원암 덤벨 로우(벤치 짚기) | 팔 내림 → 배꼽 쪽으로 당김 |
  | seatedrow | 시티드 로우 | 팔 뻗음 → 케이블을 몸 쪽으로 |
  | pulldown | 랫풀다운 | 팔 위로 → 바를 가슴 쪽으로 |
  | dips | 딥스 | 평행봉 위 → 몸을 내림 |
  | crunch | 크런치 | 누움 → 어깨를 듦 |
  | incline | 인클라인 벤치 | 바가 가슴 → 위로 밂 |
  | skull | 라잉 트라이셉스 익스텐션 | 바가 이마 쪽 → 팔 폄 |
  | pushdown | 트라이셉스 푸시다운 | 손이 가슴 앞 → 허벅지까지 밀어 내림 |

- **옆모습 원판**: 처음에는 가까운 원판이 몸을 거의 다 가렸다(바벨 로우, `/dev/avatars`에서 확인).
  - 그래서 옆모습에서는 원판을 한 단계 작게(큰 원판 6칸) 그린다.
  - 그리는 순서도 몸통 앞, 가까운 팔다리 뒤로 했다.
- `lib/liftMotion.ts`: 14종목을 새 동작에 짝지었다.
- **운동 세션 캐릭터에도 그대로 쓰인다.** 예를 들어 랫풀다운을 하면 캐릭터도 랫풀다운을 한다.
