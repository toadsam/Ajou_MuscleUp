- [ ] ★ **지도에 오늘의 사람들** — 오늘 출석한 회원이 지도에 픽셀 캐릭터로 돌아다님(실시간 아니어도 됨, 오늘 출석 목록으로 그림). 누르면 닉네임 · 연속 일수 · 응원 버튼. 빈 헬스장이 아니라 "살아 있는 동아리"로 보이게 (M, → 5장 "지도와 라운지 합치기"의 가벼운 1단계)
- [ ] ★ **출석 순간 연출** — 캐릭터가 바벨로 걸어가 원판을 꽂고 들어 올림 → 화면 흔들림 · 초크 가루 · 진동(`navigator.vibrate`) · 선택형 효과음. 레벨업이면 지도 전체 축하 (S~M, → 3장 "출석 직후 결과 창"과 합치기)
- [ ] **시간 · 계절 반영 지도** — 아침/낮/밤 조명, 비 오는 날 창밖 비, 시험 기간엔 책 든 NPC, 축제 주간 현수막. 같은 지도가 매번 조금씩 달라 "또 열어 보고 싶게" (S~M)
- [ ] **캐릭터가 기록에 반응** — 3대 무게만큼 바벨 원판 수가 다름, 연속 7일이면 땀·열기, 오래 쉬면 먼지 쌓인 캐릭터(출석하면 털어냄) (S~M, `pixelAvatar.ts`)
- [ ] **지도 숨은 재미** — 정수기 마시기, 거울 앞 포즈 이모트, 벤치에 앉기, 비밀 오브젝트 발견 시 칭호. 친구에게 말하고 싶은 거리 (S)
- [ ] **움직이는 공유 카드** — 캐릭터가 들어 올리는 2초 픽셀 애니메이션을 GIF/영상(9:16 인스타 스토리)으로 저장. 정지 카드보다 눈에 띔 (M, → 6장 "카드 렌더러 하나로" 이후)

### 7-2. 계속 오게 만들기 (리텐션)

- [ ] ★ **간단 운동 기록(세트 · 무게)** — 출석할 때 종목 3개까지 "벤치 60kg × 5 × 3" 빠르게 입력, 지난번 값 자동 채움, PR 갱신 표시 · 종목별 그래프. **헬스장에서 매일 열 이유**(다른 운동 앱 대신 이걸 쓰게)가 생기는 가장 큰 기능 (L)
- [ ] ★ **오늘의 퀘스트 3개** — 코치 NPC가 매일 줌: 출석 · 응원 1번 · 라운지 인사 같은 30초짜리. 다 하면 원판 보상. 들어올 때마다 할 일이 보이게 (M)
- [ ] ★ **동아리 협동 목표 "주간 보스 바벨"** — 이번 주 모두의 출석 수 합으로 거대 바벨을 들어 올림(진행 막대 + 기여자 목록). 달성하면 전원 보상 · 지도 장식. 개인 연속이 끊겨도 "팀에 도움"이라 다시 옴 (M)
- [ ] **"지금 운동 중" + 같이 운동 번개** — 출석 체크 시 "지금 헬스장"(2시간 뒤 자동 해제) → 지도·홈에 "지금 3명 운동 중". "오늘 7시 하체 같이 할 사람" 번개 글 + 참여 버튼. 동아리라 **실제 만남**으로 이어지는 게 가장 강한 유지 장치 (M)
- [ ] **PR 화이트보드** — 누가 3대 · 종목 개인 기록을 깨면 지도 화이트보드에 이름이 올라가고 응원이 모임 (S, 운동 기록 이후)
- [ ] **내 사물함 꾸미기** — 원판(포인트)으로 소품 · 원판 스킨 · 펫(작은 픽셀 고양이 등) 구매 → 다른 사람이 내 캐릭터 누르면 보임. 모으는 재미 (M~L, → 5장 "꾸미기 서버 저장" 필요)
- [ ] **월말 리캡 "나의 한 달"** — 운동 일수 · 가장 많이 한 요일 · 늘어난 무게 · 응원 받은 수 · 함께한 사람 카드 → 공유 (M, → 5장 "월말 리캡"과 합치기)
- [ ] **운영진 코치 피드백** — 운영진이 회원 기록에 한 줄 코멘트/루틴 추천. "누가 내 운동을 봐 준다"는 느낌 (M)
- [ ] **끊긴 연속 복구 미션** — 연속이 끊기면 "3일 안에 2번 출석하면 복구" (S, → 3장 "스트릭 보호권"과 합치기)
- [ ] **눈바디 타임랩스** — 출석 사진(본인만 보기)을 모아 한 달 변화 슬라이드 (M)

### 7-3. 추천 순서

1. **우와**: 로그인 없이 지도 체험 → 지도에 오늘의 사람들 → 출석 순간 연출 (지금 지도 엔진을 그대로 키우는 일이라 효과 대비 작업이 작음)
2. **유지**: 오늘의 퀘스트 + 주간 보스 바벨(혼자 하는 이유 + 같이 하는 이유) → 운동 기록(매일 여는 이유) → 지금 운동 중 · 번개
3. 2장 "측정"을 먼저 깔아 두면 위 기능마다 효과(재방문율)를 숫자로 비교할 수 있음
