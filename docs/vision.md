# 확장 계획 — 동아리 앱에서 "모든 운동 모임의 픽셀 헬스장"으로

2026-10-11 작성. 당장 고칠 일과 작은 기능은 [roadmap.md](roadmap.md), 이 문서는 **어디로 커 갈지**를 다룬다.

## 한 문장

> 운동하면 내 픽셀 캐릭터가 자라고, 내가 속한 모임마다 걸어 다니는 헬스장이 생기는 앱.
> 혼자여도, 동아리여도, 러닝크루여도, 헬스장 · 트레이너여도 같은 앱을 쓴다.

운동 기록 앱(플랜핏 · 번핏 · Strong · Hevy)과 **기록 기능으로 경쟁하지 않는다**.
무기는 ① 운동하면 자라는 캐릭터 ② 걸어 다니는 헬스장 지도 ③ 원판이 꽂히는 출석 — "운동을 게임처럼"이다.

---

## 1. 누가 쓰나 — 네 부류

| 부류 | 원하는 것 | 이 앱이 주는 것 |
|---|---|---|
| **혼자 운동하는 사람** | 꾸준히 하기, 기록, 재미 | 캐릭터 성장 · 출석 연속 · 원판 계산기 · 휴식 타이머 · 공개 "광장" 헬스장에서 다른 사람 구경 · 응원 |
| **대학 운동 동아리** | 출석 관리, 소속감, 행사 | 지금 아주대에서 쓰는 것 전부 + 학교 인증 + 학교 대항 리그 |
| **일반 운동 모임**(러닝크루 · 클라이밍 · 홈트 스터디 · 회사 동호회) | 같이 하는 동기, 인증, 일정 | 모임 헬스장 · 출석 인증 · 모임 챌린지 · 번개 · 종목별 지도 테마 |
| **헬스장 · PT 트레이너** | 회원이 안 그만두게, 관리 편하게 | QR 출석 · 회원 출석 현황 · 쉬는 회원 알림 · 트레이너 피드백 · (유료) |

## 2. 핵심 설계 — 모든 모임은 "짐(Gym)" 하나

네 부류를 따로 만들지 않는다. **모든 모임을 같은 단위 "짐"으로** 만들고 종류만 다르게 둔다.

```text
짐(Gym)
├─ 종류: 개인 광장(공개) | 대학 동아리 | 운동 모임 | 헬스장 | PT
├─ 지도: 픽셀 헬스장(테마: 헬스 · 러닝 트랙 · 클라이밍 · 요가 …)
├─ 멤버 역할: 주인 · 운영진(트레이너) · 멤버
├─ 기능 켜고 끄기: 출석 · 랭킹 · 게시판(자랑방) · 이벤트 · 공동구매 · 라운지 · 운영진 소개
└─ 공개 범위 · 가입 방식(바로 / 승인 / 초대 링크) · 학교 · 지역 · 로고
```

- 한 사람이 여러 짐에 속할 수 있다(동아리 + 다니는 헬스장 + 러닝크루). **캐릭터와 출석은 사람에게 하나**이고, 각 짐은 그걸 자기 지도 · 랭킹에 보여 준다.
- 어디에도 안 속한 사람은 **공개 광장**(모두의 헬스장)에 있다. 혼자 들어와도 빈 지도가 아니다.
- **아주대 동아리는 첫 번째 짐**이 된다. 지금 데이터를 그 짐으로 옮긴다.

### 지금 코드에서 바꿔야 하는 곳 (근거)

| 지금 | 바꿀 방향 |
|---|---|
| `WorkoutCrew` — 주인 · 초대 코드 · 가입 방식 · 리더/멤버 · 모임 챌린지가 이미 있음 | **이걸 "짐"의 바탕으로 키운다**(종류 · 공개 범위 · 테마 · 기능 스위치 추가). 가장 큰 자산 |
| 관리자 권한이 앱 전체에 하나(`ROLE_ADMIN`) | 앱 운영자(우리) / **짐별 운영진**으로 나눈다. 동아리 운영진은 자기 짐만 관리 |
| 이벤트 · CMS 소식 · 공동구매 · 자랑방 · 멤버/운영진 페이지가 앱 전체 하나 | 각 글에 `gym_id` → 짐마다 따로. 공개 광장 것은 모두에게 |
| 첫 화면 · 문구 · 이름이 "아주대 동아리" | 중립 브랜드("득근득근" 또는 MuscleHub) + 짐 안에서만 학교 이름 |
| `User.nickname` 은 있지만 실명(Google 이름)이 그대로 노출 | 닉네임 필수 · 변경 가능 |
| 학교 인증에 쓸 수 있는 `EmailVerification` 이 이미 있음 | 학교 이메일(@ajou.ac.kr 등)로 "○○대 인증" 배지 |
| 운영 DB 가 `ddl-auto=update` | 데이터를 짐 단위로 옮기는 큰 변경이라 **Flyway 먼저**(roadmap 6장) |

## 3. 순서 — 다 하되, 쌓이는 순서로

한 번에 다 만들 수는 없다. **앞 단계가 다음 단계의 바탕**이 되게 쌓는다.

### 0단계 · 기반 (2~3주) — 모두에게 필요

- [ ] 측정 먼저(roadmap 2장): 일별 활성, 핵심 이벤트, 유입 경로
- [ ] Flyway 도입 → **짐 데이터 구조**(WorkoutCrew 확장) → 아주대 데이터를 첫 짐으로 이전
- [ ] 짐별 운영진 권한(앱 운영자와 분리)
- [ ] 브랜드 중립화(첫 화면 · 공유 미리보기 · 문구), 서비스 이름 하나로
- [ ] 닉네임 필수 · 시작 안내(`/welcome`)
- [ ] **카카오 로그인**(한국 일반 사용자 기본)
- [ ] 이용약관 · 개인정보 처리방침 · 신고 · 차단 · 사진/채팅 관리 도구 — 모르는 사람끼리 쓰는 순간 필수
- [ ] 운영비 점검(사진 저장 용량 · 서버) — 사용자가 늘어도 감당되는지

### 1단계 · 혼자 + 대학 동아리 (3~4주)

같은 엔진으로 두 부류를 함께 연다.

- [ ] **혼자**: 공개 광장 지도(지금 운동 중인 사람들이 돌아다님), 원판 계산기 · 휴식 타이머 · 간단 기록, 로그인 없이 체험(완료)
- [ ] **동아리**: 누구나 "우리 동아리 짐 만들기"(셀프 서비스) → 초대 링크 → 운영진 지정 → 기능 켜고 끄기
- [ ] 학교 이메일 인증 → 학교 배지
- [ ] 동아리 템플릿: 운영진 소개 · 공동구매 · 행사 · 신입 기구 투어(코치 NPC)
- [ ] 다른 대학 동아리 2~3곳과 시범 운영(아주대 운영진 인맥)

### 2단계 · 학교 대항 + 모든 운동 모임 (4~6주)

- [ ] **학교 대항 리그**: 학교별 주간 출석 합계 · 1인당 평균으로 순위, 시즌 보상(학교 현수막이 지도에)
- [ ] 짐 종류 "운동 모임" 열기: 러닝크루 · 클라이밍 · 홈트 · 회사 동호회
- [ ] **종목별 지도 테마**: 헬스장 → 러닝 트랙 · 클라이밍장 · 요가 스튜디오. 캐릭터 장비도 종목별
- [ ] 출석 인증 일반화(사진 · 운동 앱 기록 · 위치 중 고르기)
- [ ] 모임 찾기(지역 · 종목 · 학교), 번개 · "지금 운동 중"

### 3단계 · 헬스장 · 트레이너 + 앱스토어 (6주~)

- [ ] **헬스장 짐**: 실제 장소 등록, 입구 **QR 출석**(현실의 체크인 → 지도 속 체크기에 원판), 혼잡도
- [ ] 운영 화면: 회원 출석 현황 · 2주 이상 쉰 회원 목록 · 한 번에 응원/알림
- [ ] **PT 트레이너**: 담당 회원 기록 보기 · 한 줄 피드백 · 숙제 운동 · 출석 리포트
- [ ] 앱스토어 등록(PWA 를 감싸는 방식) + 푸시 알림
- [ ] 결제(헬스장 · 트레이너 유료 요금제)

## 4. 돈은 어디서

| 대상 | 방식 | 시기 |
|---|---|---|
| 개인 | 무료. 꾸미기(원판 스킨 · 소품 · 펫) · 시즌 패스 유료 아이템 | 2단계 이후 |
| 동아리 · 운동 모임 | 무료(퍼지는 통로). 큰 모임용 고급 기능(통계 · 맞춤 지도)만 유료 검토 | 나중 |
| 헬스장 · 트레이너 | **월 구독**(회원 관리 · QR 출석 · 이탈 알림) | 3단계 |

## 5. 정해야 할 것 · 위험

- **서비스 이름**: 득근득근 / MuscleHub(도메인 musclehub.co.kr) 중 하나로. 동아리 밖 사람에게도 통하는 이름인지
- **아주대 회원 영향**: 데이터를 짐으로 옮길 때 기존 기록 · 랭킹 · 캐릭터가 그대로인지 검증 계획 필요
- **종목 확장 범위**: 헬스 외 종목은 캐릭터 · 지도 그림이 새로 필요(그림 작업량 큼). 러닝 하나 먼저 추천
- **콘텐츠 관리**: 사진 · 채팅 신고 처리를 누가 하나(초기엔 우리 + 짐 운영진)
- **운영비**: 사진 저장 · 실시간 서버 비용이 사용자 수에 비례
- **개인정보**: 몸무게 · 체성분 · 사진은 민감 정보 → 공개 범위 기본값을 "나만"

## 6. 잘되고 있는지 보는 숫자

- **주간 운동한 사람 수**(주 1회 이상 출석) — 가장 중요한 숫자
- 새로 온 사람의 4주 뒤 남은 비율(혼자 온 사람 / 모임으로 온 사람 따로)
- 새로 만들어진 짐 수, 짐 하나당 주간 활동 인원
- 초대 링크 1개당 가입 수
- (3단계) 유료 헬스장 · 트레이너 수
