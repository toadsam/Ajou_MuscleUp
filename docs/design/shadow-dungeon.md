# 설계 — 그림자 던전(2차): 운동이 탄약, 던전에서 쏘기

작성 2026-10-19. 1차(`shadow-boss.md`, PR #52)가 머지된 뒤 **main 기준** 별도 PR 들로 만든다.
사용자 요청: "지도에서 던전으로 들어가면 전체 화면이 되고, 능력치와 조건에 따라 생기는 스킬로 내가 몬스터를 잡는 느낌".
결정(사용자와 합의): **던전 · 스킬 · 능력치 · 전체 화면은 하고, 조이스틱 실시간 조작은 하지 않는다.**

---

## 0. 왜 만드나

- 1차 그림자는 "결과 화면에 붙은 연출"이다. 저장을 누르면 혼자 때리고 끝난다. 내가 고를 게 없으니 몇 번 보면 건너뛰기를 누른다.
- 게임이 되려면 **내 선택**(어떤 기술을 언제 쓸지)과 **내 성장이 보이는 수치**(능력치)가 필요하다.
- 단, 이 앱의 공식 "**진짜 운동 = 공격**"은 깨지 않는다. 운동 안 한 사람은 던전에서 할 수 있는 게 없어야 하고, 조작 실력으로 운동을 대신할 수 없어야 한다.

한 줄: **운동으로 힘을 모으고(탄약), 던전에 들어가 그 힘을 어떤 기술로 어떤 순서로 쏠지 고른다.** 조작은 "선택 + 타이밍", 총량은 서버가 지킨다.

## 2. 규칙 (게임 디자인)

### 2.1 능력치 — 전부 이미 있는 기록

| 능력치 | 값 | 출처 | 던전에서 하는 일 |
|---|---|---|---|
| **힘** | 3대 추정 1RM 합(kg) | `LiftService.bests()` bigThree | 표시 + 패시브 "삼대장"(2.5) |
| **지구력** | 최근 4주 러닝 거리(km) | `RunRepository` 4주 합 | 표시 + 패시브 "장거리" |
| **끈기** | 출석 연속일 · 주간 목표 연속 주 | 출석 · `WeeklyGoalService` | 표시 + 패시브 "꾸준함" |
| **레벨** | 캐릭터 레벨 | `CharacterGrowthService` | 치명타 배율(1차 그대로 `1.5 + 레벨×0.01`) |

능력치는 **데미지 총량을 늘리지 않는다**(패시브 상한 2.5). 성장은 "보이는 숫자"와 "쓸 수 있는 기술"로 느낀다.

### 2.2 힘 모으기 — 저장은 공격이 아니라 충전

- 운동 세션 · 러닝 · (기록 직접 입력도 1차와 같이) 저장하면 **힘이 그 주의 탄약 통에 쌓인다**. 계산은 1차 `ShadowRules` 그대로(볼륨/100 + 맨몸 20kg/회, 러닝 100m = 1, 최소 1, **하루 상한 300** 은 모은 힘에 적용).
- 탄약 통은 **기술별 5개**(2.3). 세션의 각 종목 볼륨은 종목의 `category` 로 나뉘어 들어간다(한 세션이 하체 40 + 가슴 25 처럼). 러닝은 전부 "돌진" 통.
- **치명타 토큰**: 그 저장에서 PR 이 나오면 토큰 +1(세션당 최대 1, 1차와 같음). 던전에서 **내가 고른 한 타**에 쓴다 — 1차의 "자동 치명타"가 전략이 된다.
- 저장 결과 화면의 연출은 "충전": 내 캐릭터가 동작 1회 → 원판이 날아가 던전 입구에 쌓이며 "+68 모음" → **[던전 가서 쓰기]** 버튼. 1차 전투 연출은 던전 안으로.
- 세션 · 러닝 **삭제** 때: 아직 안 쓴 힘이면 통에서 뺀다. 이미 쓴 힘이면 1차처럼 재계산(피해를 깎되 처치 · 보상은 유지).

### 2.3 기술 — 운동 종목이 기술이다

이번 주에 **실제로 한 종목의 기술만 켜진다.** 통이 비면 회색.

| 기술 | 통(종목 category) | 연출 | 한 번 누르면 |
|---|---|---|---|
| **지진** | 하체 `LEGS` | 점프 → 착지, 바닥 전체 흔들림(`dg-quake-hard`), 큰 숫자 하나 | 통에서 최대 **60** 사용, 1타(heavy) |
| **밀어내기** | 가슴 `CHEST` | 벤치 자세로 밀치기, 그림자 넉백 가장 멀리 | 최대 60, 1타(heavy) |
| **들어 던지기** | 등 `BACK` | 데드리프트로 들어 올려 내려찍기, 2타(들기 · 찍기) | 최대 60, 2타 [0.3, 0.7] |
| **연타** | 어깨 · 팔 · 코어 · 기타 `SHOULDERS` `ARMS` `CORE` `OTHER` | 잽 4~5연타, 작은 숫자 여러 개 | 최대 60, 4타 균등 |
| **돌진** | 러닝 `RUN` | 트랙 달리기로 관통, 그림자 뒤로 지나감 | 최대 60, 1타 |

- "60" = 세트 묶음 하나. 통이 60보다 작으면 남은 만큼. 통이 바닥날 때까지 **계속 누를 수 있다**(한 주 300 모았으면 5번 정도). 상수 `ShadowRules.STRIKE_CHUNK`.
- 기술은 **데미지 총량을 바꾸지 않는다.** 바꾸는 건 분배 · 순서 · 연출 · 어디에 치명타를 쓸지 · 타이밍 보너스(2.4)다.
- 통 이름은 코드 상수(`ShadowSkill` enum 대신 **문자열 코드** `LEGS` `CHEST` `BACK` `ARMS` `RUN` — enum 칸 금지 규칙).

### 2.4 조작 — 조이스틱 대신 "타이밍"

1. 기술 원판을 **탭** → 내 캐릭터가 준비 동작(0.4초). 동시에 아래에 **타이밍 게이지**: 바벨 위를 원판이 좌→우로 미끄러진다(0.8초, 한 번).
2. 원판이 가운데 링을 지날 때 **탭**. `PERFECT`(가운데 ±6%) · `GOOD`(±15%) · `MISS`(그 외 · 안 누름).
3. 보너스: PERFECT **+10%** · GOOD **+5%** · MISS 0. **그 타의 10% 가 상한**(한 주 전체로도 ≤ 10%). 상수 `TIMING_PERFECT_PCT` · `TIMING_GOOD_PCT`.
4. 탭한 순간 서버에 `POST /api/shadow/dungeon/strike {skill, grade, crit}` → 응답(`Hit`)으로 연출. 왕복 시간은 준비 동작 뒤에 숨는다(약 100ms).

왜 타이밍인가: 한 손 · 세로 화면 · 헬스장에서 10초. "운동할 때 호흡 맞추기"와 같은 감각. 서버는 `grade` 를 클라이언트 말대로 믿지만 **보너스 상한 10%** 라 속여도 얻는 게 작다(기록에 적는다).

### 2.5 조건 해금 — 패시브 4개 (운동 동기와 겹치는 것만)

| 이름 | 조건(그 주 · 서버가 계산) | 효과 | 상한 |
|---|---|---|---|
| **삼대장** | 3대 추정 1RM 합 ≥ 300kg(여 200kg) | 지진 · 밀어내기 · 들어 던지기 +5% | 모든 패시브 합 **≤ +15%** |
| **장거리** | 이번 주 러닝 ≥ 10km | 돌진이 2연속(같은 힘을 2타로, 연출만) + 돌진 +5% | |
| **꾸준함** | 이번 주 출석 ≥ 3일 | 모든 기술 +5% | |
| **그림자 사냥꾼** | 칭호 `T_SHADOW_STREAK_4` 보유 | 치명타 배율 +0.1 | |

조건은 `ShadowBossService.passives(user)` 가 매 strike 때 다시 계산한다(저장 안 함, 꾸미기 `GymDecorService` 와 같은 방식). 던전 화면 위에 켜진 패시브가 작은 칩으로 보인다. 숫자는 전부 `ShadowRules` 상수 — 돌려 보고 바꾼다.

### 2.6 정산 — 안 쓴 힘은 버리지 않는다

- 던전에 안 들어가도 손해가 없어야 한다(라운지만 쓰는 사람). **주가 끝나면(월요일 00:05 KST, `@Scheduled`) 남은 힘을 보너스 없이 기본 공격으로 자동 정산**한다. 치명타 토큰은 가장 큰 통에 자동 사용.
- 보조: `status()` · `history()` 를 읽을 때 지난 주에 미정산 힘이 있으면 그 자리에서 정산(스케줄러가 못 돌았을 때).
- 그래서 1차 규칙(처치 · 연속 · 칭호)은 결과적으로 유지된다. 던전은 "보너스 ≤ 10% + 내 손으로 잡는 느낌"을 더하는 것.
- 1차 데이터 호환: 이미 공격이 적용된 과거 주는 `charge` 0 · `settled` true 로 그대로.

### 2.7 공정성 요약

| 올릴 수 있는 것 | 상한 |
|---|---|
| 타이밍 | 그 타의 10% |
| 패시브 | 합 15% |
| 치명타 | 1차와 같은 조건(PR) · 횟수(세션당 1) — 자리만 고름 |
| 힘 총량 | **운동으로만**, 하루 300 |

## 3. 데이터 구조

새 표 1개 + 칸 추가(`ddl-auto=update`, 추가 칸은 전부 기본값 있는 숫자 · 불린 · 문자열).

**`shadow_charges`** (새 표) — 저장 한 번 = 한 줄. 하루 상한 · 삭제 재계산의 기준
```
id, week_id(FK shadow_weeks), user_id, source VARCHAR(10) SESSION|RUN, source_id,
skill VARCHAR(10) LEGS|CHEST|BACK|ARMS|RUN, raw INT, hit_on DATE, crit_token BIT, created_at
```
- 1차 `shadow_hits` 의 `source` · `source_id` · `hit_on` 역할이 여기로 온다. **충전과 타격을 한 표에 섞지 않는다.**

**`shadow_weeks`** 추가
```
charge_legs  INT NOT NULL DEFAULT 0   -- 안 쓴 힘(기술별)
charge_chest INT NOT NULL DEFAULT 0
charge_back  INT NOT NULL DEFAULT 0
charge_arms  INT NOT NULL DEFAULT 0
charge_run   INT NOT NULL DEFAULT 0
crit_tokens  INT NOT NULL DEFAULT 0   -- 안 쓴 치명타
settled      BIT NOT NULL DEFAULT 1   -- 주 끝 정산 끝났나(이번 주는 0)
visits       INT NOT NULL DEFAULT 0   -- 던전 들어온 횟수(통계용)
```

**`shadow_hits`** 추가 (던전 타격 · 자동 정산 타격)
```
skill  VARCHAR(10) NULL   -- LEGS CHEST BACK ARMS RUN, 자동 정산이면 NULL
grade  VARCHAR(10) NULL   -- PERFECT GOOD MISS, 자동이면 NULL
bonus  INT NOT NULL DEFAULT 0   -- 타이밍 + 패시브로 더해진 피해
```
- 탈퇴: `AccountDeletionService` 에 `ShadowCharge` 추가 + `AccountSafetyTest`.
- 레이드(3차) 대비: `shadow_hits.crew_id` 는 **지금 안 넣는다**. 넣을 때 칸 추가로 충분.

## 4. API

| 메서드 | 경로 | 내용 |
|---|---|---|
| GET | `/api/shadow` | 1차 응답 + `charge: {LEGS, CHEST, BACK, ARMS, RUN}` · `critTokens` · `passives: ["삼대장", …]` · `stats: {strengthKg, enduranceKm, attendanceStreak, weeklyStreak, level}` |
| POST | `/api/shadow/dungeon/enter` | `visits+1`, 응답은 GET 과 같음(통 · 패시브 · 체력). 들어올 때 한 번 |
| POST | `/api/shadow/dungeon/strike` | 몸 `{skill, grade, crit: boolean}` → `Hit`(1차 `ShadowHitResponse` + `skill` · `grade` · `bonus` · `shares: [..]` 연타 분배 · `chargeLeft` · `critTokensLeft`). 통이 비면 400 한국어 문구, 이미 쓰러졌으면 200 + `alreadyDown` |
| GET | `/api/shadow/history` | 1차 그대로 |
| 저장 응답 `shadow` | `POST /api/workouts` · `/api/runs` | `{charged: {LEGS: 40, CHEST: 25}, total: 65, critToken: boolean, capped: boolean, chargeLeft: {...}}` — 1차 `Hit` 모양에서 바뀜(화면 PR 과 같이) |

이메일 · 사용자 번호 없음(1차 규칙). `/api/shadow/**` 권한은 1차 설정 그대로.

## 5. 화면

### 5.1 들어가는 길 3곳

1. **홈 지도** 1층 입구 매트의 공간 목록에 "그림자 던전"(픽셀 문 그림: 어두운 문틀 + 빨간 눈 두 점). 고르면 `navigate("/shadow/dungeon")`. 잠금 없음(SPACE 물품 아님).
2. **홈 한 줄**(`ShadowHomeRow`): "그림자 ████░░ 228 남음 · 모은 힘 120 → 던전". 모은 힘이 0이면 "운동하고 힘 모으기".
3. **저장 결과 화면**: 충전 연출 뒤 **[던전 가서 쓰기]**.

### 5.2 던전 화면 `pages/ShadowDungeon.tsx` (`/shadow/dungeon`) — 전체 화면

앱 껍데기(머리 · 탭바) 밖 라우트. 세로 375px 기준, 데스크톱은 가운데 420px 기둥.

```
┌─────────────────────────────┐ steel-950 바탕(밤의 헬스장: 어두운 고무 매트 + 초크 가루 빛 점)
│ ←  그림자            Lv 14  │
│ ███████████░░░░░  412 / 640 │ HpBar(1차) 크게
│                             │
│   [나]              [그림자] │ 무대: dg-rubber, 중앙 플랫폼 테이프 선
│  힘 320 · 지구력 12 · 끈기 9 │ 능력치 칩 3개(font-num)
│  [삼대장] [꾸준함]           │ 켜진 패시브 칩(plate-yellow)

│                             │
│  (●)   (●)   (●)   (●)  (●) │ 기술 원판 5개: 빨강 지진 · 파랑 밀어내기 · 노랑 들어 던지기 · 초록 연타 · 하양 돌진
│  120    60    0     45   30 │ 남은 힘(0 이면 회색 · 눌러도 "이번 주 가슴 운동 없음")
│        [초크 통 ×1 치명타]    │ 토큰 있으면 켜짐, 켜 두고 기술을 누르면 그 타가 치명타
```

흐름: 들어오면 그림자가 어둠에서 걸어 나와 선다(0.6초) → 기술 탭 → 준비 동작 + 게이지 → 탭 → 1차 `BossFight` 연출(기술별 변형) → 숫자 · 등급 도장(`PERFECT!` 노랑 · `GOOD` 초크 · `MISS` 회색) → 다음 기술. 통이 전부 0 이면 "모은 힘을 다 썼어요 — 운동하고 다시 와요" + [홈]. 처치하면 1차 DOWN → 전리품 → **[공유 카드]**(1차 PR 3 내용을 여기서) → [홈].
나가기(←) 는 언제든. 쓴 힘은 서버에 이미 반영됐으니 잃는 것 없음.

### 5.3 기술 연출 — 1차 `BossFight` 를 기술별로 변형

`BossFight` 를 `FightScene`(무대 · 두 캐릭터 · HpBar · 흔들림)과 `strike(plan)`(한 기술의 타 순서)로 나눈다. 연출 변형은 `kind` 와 `shares` 만 다르다.

| 기술 | 내 동작(`liftMotion`) | 그림자 | 추가 |
|---|---|---|---|
| 지진 | `squat` 2프레임 + 점프 착지 | 공중에 뜸 → 떨어짐 | `dg-quake-hard` 400ms, 바닥 균열 SVG 1장 |
| 밀어내기 | `bench` 서서 밀기 | 넉백 60px(`--knock` 변수) → 벽에 닿아 흔들림 | 벽 먼지 조각 4개 |
| 들어 던지기 | `deadlift` 들기 → 내려찍기 | 들려 올라감(translateY −40px) → 찍힘 | 2타 숫자 |
| 연타 | `pullup`/`row` 팔 2프레임 빠르게 | 작은 넉백 4번 | 작은 숫자 4개 연속 `dg-float` |
| 돌진 | `run` | 관통(그림자 뒤로 지나가며 `scaleX(-1)`) | 잔상 3장(픽셀 복제 opacity 단계) |

새 픽셀 그림 없음(1차 규칙). 전부 기존 동작 + CSS. 블러 · 글로우 금지는 그대로.

### 5.4 저장 결과 화면(운동 · 러닝) — "충전"

1차 `BossFight` 자리에 `ChargeScene`: 내 캐릭터 동작 1회 → 원판 `n`개(힘/60, 최대 5)가 오른쪽 "던전 문"으로 날아가 쌓임 → "하체 +40 · 가슴 +25" → 치명타 토큰이면 초크 통이 반짝 → **[던전 가서 쓰기]** / 상한이면 "오늘 300 다 모았어요". 1.2초.

### 5.5 전적 화면 `/shadow` — 1차 유지 + 통 현황

맨 위에 "모은 힘" 원판 5개(5.2 와 같은 부품) + [던전 들어가기]. 다시 보기는 던전 strike 기록으로.

### 5.6 개발 확인 `/dev/boss` → `/dev/dungeon`

가짜 통 · 토큰 · 패시브를 켜 둔 던전 화면(서버 없이 `strike` 를 로컬 규칙으로 흉내). 기술 5개 · 등급 3개 · 처치를 로그인 없이 본다.

## 8. 결정이 필요한 것 (사용자)

1. **저장 즉시 공격을 완전히 없앨지**(추천: 없애고 "충전"으로. 둘 다 두면 "왜 던전에 가야 하지"가 없어진다).
2. **한 번 누름 = 60**, 타이밍 **+10% / +5%**, 패시브 **합 15%**, 삼대장 **300kg(여 200kg)** — 숫자 감. 상수 한 곳이라 돌려 보고 바꾼다.
3. **자동 정산 시각** 월요일 00:05 KST(추천) vs 일요일 밤 푸시 뒤 23:59.
4. **기술 5개 묶음**: 어깨 · 팔 · 코어 · 기타를 "연타" 하나로 묶는 것이 맞는지(코어만 따로 "버티기"는 공격이 아니라 뺐다).
5. **던전 들어가기 횟수 제한 없음**(추천 — 통이 상한) vs 하루 1회.
6. 3차 **모임 레이드**(모임원이 같은 그림자를 각자 운동으로 때리고 던전에서 함께 침)를 언제 — 2차를 2~3주 쓴 뒤 추천. 데이터는 `crew_id` 칸 추가로 열 수 있게 두었다.

## 9. 일부러 안 하는 것

- 조이스틱 · 이동 · 회피 · 적 패턴(실시간 액션). 운동 없이 손가락으로 이기는 길이 생기고, 만드는 비용이 다른 차원.
- 능력치가 데미지 총량을 올리는 것(힘 300kg 이라고 더 세게 때리지 않는다 — 운동한 양만).
- 새 보스 종류 · 새 픽셀 아트 · 효과음(1차 규칙 그대로).
- 기술 장착 · 스킬 트리 · 쿨타임(이번 주 한 운동이 곧 기술 — 더 복잡하게 안 한다).
- 던전 안 실시간 다른 사람(3차 레이드에서).
