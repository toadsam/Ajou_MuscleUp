# 설계 — 그림자 던전 지도판: 걸어 다니는 던전, 운동이 힘, 보상은 꾸미기

작성 2026-10-20. `shadow-dungeon.md`(2차)의 **화면 부분(5절)을 이 문서가 대신한다.** 힘 모으기 · 통 5개 · strike · 정산 같은 규칙과 백엔드는 그 문서와 PR #54 그대로 쓴다.

사용자 요청(2026-10-20): "지도처럼 움직이고 던전에 들어가서 지도처럼 있고, 그때는 조이스틱으로 움직이고, 몬스터를 만나면 스킬을 쓰면서 죽이는 것. 컨트롤에 따라 갈리는 건 거의 없도록. 보상은 제안해 달라."
합의한 한 줄: **운동하면 힘이 생기고, 그 힘으로 던전에서 몬스터를 잡고, 잡으면 캐릭터와 헬스장을 꾸밀 것을 받는다.**

## 1. 원칙 세 가지

1. **걷기는 공짜, 싸움은 운동한 만큼.** 운동을 안 한 날에도 던전을 둘러보고 몬스터가 어디 있는지 볼 수 있다. 스킬은 그 주에 한 운동의 통만 켜진다. "저거 잡으려면 운동해야겠다"가 목표.
2. **조작은 결과를 거의 바꾸지 않는다.** 몬스터는 쫓아오지도 공격하지도 않는다. 내 캐릭터는 체력이 없고 죽지 않는다. 전투는 고르기 + 작은 타이밍(최대 +5%)뿐. 차이를 만드는 건 **힘을 어디에 쓸지(배분)**.
3. **보상은 꾸미기와 자랑만.** 데미지를 올리는 장비 · 능력치 보상은 없다. 그래야 "운동한 만큼만 강해진다"가 지켜진다.

### 2.3 맵 구성 (한 장, 위가 안쪽)

```
┌──────── 보스 방 ────────┐   그림자(보스) — 큰 원판 무대 위. 문은 잡몹을 안 잡아도 열려 있음
│        [그림자]         │
└──────────┬─────────────┘
┌─ 방 B ───┴──── 방 C ────┐   잡몹 2마리씩(순찰). 벽에 원판 랙 · 거울 같은 소품(1층 그림 재사용)
│ [야식 슬라임] [알람]     │
└──────────┬─────────────┘
┌──────── 방 A ───────────┐   잡몹 1~2마리 + (가끔) 희귀 잡몹
│   [내일부터]            │
└──────────┬─────────────┘
```

- 바닥: 어두운 고무 매트(steel-950 계열) + 초크 가루 점. 벽: 볼트 철판. 짐 플로어 v2 색만 쓴다(블러 · 글로우 X).
- 맵은 **주마다 같은 모양**(1차는 고정 한 장). 몬스터 배치만 주마다 시드로 조금 바뀐다(사용자 id + 주 시작일).

### 2.4 HUD (맵 위에 떠 있음)

- 위: ← 나가기 · "그림자 던전" · 보스 남은 체력 작은 바 · Lv.
- 오른쪽 위: 통 5개 작은 원판 + 숫자(누르면 펼쳐서 능력치 · 패시브).
- 아래 오른쪽: 치명타 토큰 수.
- 몬스터 머리 위: 이름표 + 작은 체력 바(잡은 몬스터는 회색으로 쓰러져 있음).

## 3. 몬스터

### 3.1 잡몹 (헬스하는 사람의 적)

| 코드 | 이름 | 모습(새 그림 최소) | 체력 |
|---|---|---|---|
| `TOMORROW` | 내일부터 | 달력 한 장에 다리 | 보스 체력 × 10% |
| `MIDNIGHT_SNACK` | 야식 슬라임 | 주황 슬라임(사각형 몇 개) | × 12% |
| `SNOOZE` | 알람 스누즈 | 자명종 + 눈 | × 10% |
| `EXCUSE` | 핑계 | 말풍선 모양 유령 | × 14% |
| `SOFA` (희귀) | 소파 괴물 | 소파 + 빨간 눈 | × 20%, 조각 많이 |

- 한 주에 4마리(+ 희귀는 조건부, 4.3). 체력은 그 주 보스 체력 비율, 최소 15.
- 그림: 기존 그림자 스프라이트처럼 **사각형 몇 개로 그리는 작은 픽셀**(16×16 안팎). 새 그림은 이 5개만. 피격 · 쓰러짐 연출은 그림자와 같은 CSS(`dg-hit` · `dg-collapse` · 조각).
- 움직임: 방 안에서 2~4칸을 천천히 왕복(32px/초). 플레이어를 쫓지 않는다. 내가 닿거나 탭하면 그 자리에 멈추고 전투.

### 3.2 보스

- 지금의 그림자 그대로(체력 = 지난 4주 평균 × 1.05, 처치 보상 · 연속 · 휴식 주 규칙 그대로).

## 4. 전투

### 4.1 흐름

1. 몬스터와 닿으면 맵 위에 **전투 창**이 아래에서 올라온다(맵은 어둡게, 멈춤).
2. 창 = 지금의 `DungeonStage`(무대 · 두 캐릭터 · 체력 바) + `TimingGauge` + `SkillPlates`. 상대 그림만 몬스터로 바뀐다(`DungeonStage` 에 `foe` prop).
3. 기술 원판 탭 → 게이지 → 탭 → `strike(target, skill, grade, crit)` → 연출. 지금과 같다.
4. 몬스터가 쓰러지면 보상 칩이 뜨고 창이 내려간다. 맵에는 쓰러진 몬스터가 회색으로 남는다.
5. **언제든 "물러나기"**: 창이 내려가고 몬스터는 깎인 체력 그대로 남는다(다음에 이어서).

### 4.2 숫자 (조작 영향 최소)

- 한 번 누르면 통에서 60(지금과 같음). 잡몹 체력이 작으면 남는 만큼은 **통으로 돌려준다**(과잉 소모 없음 — 잡몹에 오버킬 없음). 보스만 오버킬.
- 타이밍: **PERFECT +5% · GOOD +2% · MISS 0**(지금 10 · 5 에서 낮춤). `ShadowRules.TIMING_*` 상수만 바꾼다.
- 패시브 합 15%, 치명타 토큰은 그대로.
- 조작이 바꿀 수 있는 최대치 = 한 타의 5%. 한 주 전체로 봐도 5% 이하.

### 4.3 배분이 전략

- 통은 하나라서 잡몹을 잡을수록 보스에 쓸 힘이 줄어든다. 잡몹 = 조각 · 도감, 보스 = 상자 · 칭호 · 연속.
- 예: 한 주 힘 300, 보스 체력 250, 잡몹 4마리 합 115 → 다 잡으려면 365 필요. 운동을 더 하거나, 고르거나.
- 남은 힘은 주 끝에 **보스에게만** 자동 정산(지금 규칙). 잡몹은 자동으로 잡히지 않는다(직접 들어와 잡는 재미).

## 6. 데이터 · API (PR #54 위에 더함)

**새 표 `shadow_mobs`** — 한 사람 한 주의 잡몹 한 마리
```
id, week_id(FK shadow_weeks), user_id, code VARCHAR(20), hp INT, damage INT,
killed_at DATETIME NULL, slot INT(맵 자리 번호), created_at
```
- 주 행이 처음 생길 때 시드로 4마리(+희귀) 만든다. 문자열 코드(enum 칸 금지). 탈퇴에 추가.

**바뀌는 API**
| 메서드 | 경로 | 내용 |
|---|---|---|
| POST | `/api/shadow/dungeon/enter` | 응답에 `mobs: [{id, code, name, hp, remaining, killed, slot}]` 추가 |
| POST | `/api/shadow/dungeon/strike` | 몸에 `target`(`"BOSS"` 또는 잡몹 id). 잡몹이면 오버킬 없이 남는 힘은 통으로, 응답에 `mob` · `reward.shards` · `reward.monsterCard` |

**누적 처치**: `GymDecorItem.Goal` 에 `SHADOW_KILLS("그림자 처치 %d번")` · `MOB_KILLS("던전 몬스터 %d마리")`, 꾸미기 물품 4개. 얻었는지는 기록에서 계산(저장 안 함 — 꾸미기 규칙 그대로).

**정산**: 주 끝에 남은 잡몹은 그대로 사라진다(보상 없음). 남은 힘은 보스로(지금 규칙).
