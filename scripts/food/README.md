# 음식 검색 데이터 (backend/src/main/resources/food/foods.tsv.gz)

식단 기록의 음식 검색(`GET /api/diet/foods`)이 쓰는 영양 정보. 서버가 뜰 때 `FoodCatalogService` 가 줄 수를 비교해 `food_items` 표에 넣는다.

## 출처 (화면에 출처 표시 필수)
| 파일 | 출처 | 판 | 받은 곳 |
|---|---|---|---|
| 가공식품 DB (엑셀, 196MB) | 식품의약품안전처 식품영양성분 데이터베이스(K-FIND) | 2026-09-29 | various.foodsafetykorea.go.kr/nutrient → 영양성분 DB 내려받기(활용정보 양식 제출) |
| 음식 DB (엑셀, 12MB) | 같은 곳 | 2026-08-28 | 같은 곳 |
| 국가표준식품성분 DB 10.4 (엑셀, 13MB) | 농촌진흥청 국립식량과학원 | 10.4 | www.nics.go.kr/food → 국가표준식품성분표 개요 → DB(Excel) 다운로드. 공공누리 제1유형(출처표시) |

- K-FIND 는 활용 시 출처를 "식품영양성분 데이터베이스"로 표기하라고 안내한다. 화면 문구: `lib/foodSearch.ts` 의 `FOOD_DATA_CREDIT`.
- 원본 엑셀은 저장소에 넣지 않는다(크다). 이 폴더의 스크립트로 검색에 필요한 칸만 추린다.

## 만드는 법
```bash
python -I scripts/food/build_food_catalog.py <엑셀 3개가 있는 폴더> backend/src/main/resources/food/foods.tsv.gz
```
폴더 안 파일 이름: `kfind_01.xlsx`(가공식품) · `kfind_02.xlsx`(음식) · `rda_raw.xlsx`(원재료).

- 칸: `src`(P 가공식품 · D 음식 · R 원재료) `name` `maker` `basis`(100g|100ml) `kcal` `protein` `fat` `carb` `serving_g`(1회 섭취참고량 · 음식은 1인분) `package_g`(포장 전체).
- 가공식품: 업체는 유통업체 → 제조사 → 수입업체 순, "(주) · 주식회사 · 제2공장 · ○○지점" 등은 뺀다. 이름과 영양값이 같으면(공장 · 유통사만 다른 같은 제품) 하나만.
- 1회 섭취참고량은 식품 분류별 기준량이라 실제 한 번 먹는 양과 다를 수 있다(100g 닭가슴살 한 팩이 30g). 화면은 포장이 500 이하면 포장 전체를 기본 양으로 쓴다.
- 음식: 같은 음식이 급식 · 외식 등으로 여러 줄 → 이름당 하나(급식이 아닌 것 우선).
- 원재료: 가장 최신 시트(Database 10.x)만.
- 2026-10-12 기준 322,856건(가공식품 303,843 · 음식 15,647 · 원재료 3,366), 압축 7.1MB.

## 갱신
새 판을 받아 다시 만들고 커밋하면, 배포 뒤 서버가 줄 수가 달라진 것을 보고 표를 통째로 다시 넣는다(처음 한 번 몇 분, 그동안은 이전 데이터로 검색).
